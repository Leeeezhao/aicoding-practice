## 推荐练法（对齐真实机考）

1. **先读 README，别让 AI 一把梭写代码。**
2. 第一轮只让 AI：复述目标 / 必做项 / 输入输出 / 边界 / 交付物。
3. 拆成小模块，**一次只做一个模块**，做完就跑本地测试。
4. 报错时贴原错，并写清「只修这个，别动别处」。
5. 交卷前对照 README 逐条自检；结果跑不通时过程分通常不算。
